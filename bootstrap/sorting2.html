💻 Bubble Sort Explained 

repeat many times {

    compare item 1 and item 2

    if left item is bigger {

        swap them

    }

    move to next pair
}

🧠 Easy way to remember

1. Look at two neighbors.

2. Compare them.

3. Swap if they are in the wrong order.

4. Move one place to the right.

5. Repeat until sorted.
